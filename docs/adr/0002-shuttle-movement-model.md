# 0002 — Shuttle: 惯性滑翔运动模型

日期：2025（grill 会话定案）
状态：Accepted

## 背景

玩家获得「按 E 蓄力弹射 → 进入空中穿梭机模式 → 落地退出」的能力。需要决定空中操控模型、与碰撞/退出的关系。

## 决策

1. **弹射（Eject）**：按住 E 蓄力（左缘竖条 + 画面暗角随蓄力加深），松手发射；满蓄 ≈ 60m+。蓄力仅在任意可站立固体表面有效；空中按 E 无效果。
2. **运动模型 = 半重力滑翔**：重力 ~4 m/s²（弱于真实），升力随速度增强——速度撑高度，不推进自然缓降。SHIFT = 沿视线方向推进（峰值 65 m/s），常规上限 40 m/s。W/S 俯仰加速，转向带惯性。
3. **实心世界**：空中与建筑碰撞为实体（复用 AABB），楼顶为合法落点。
4. **Touchdown**：接触任何固体表面即退出 Shuttle。垂直速度 <15 m/s 为软着陆（速度清零+镜头轻沉）；≥15 m/s 为重落（阻尼反弹一次 + 震屏），随后同样落地。
5. **300m 软天花板**：超过后推力渐衰；Altitude Rail 刻度至 320m。
6. **反馈**：右缘 Altitude Rail（10m 刻度 / 50m 标注线 / 玩家指针，绝对海拔，街道=0m）；HUD 状态行 `SHUTTLE: ALT xxm VEL xx`；FOV 随速度 52→58。CRT 模式下 Rail 照常显示（仅配色变化）。

## 理由

- 惯性滑翔与第一人称 Walk 形成操作反差且自带速度上限，不会退化为传送。
- 楼顶合法化让实心碰撞成为乐趣而非阻碍，也让新建筑的天线/腰线/檐口有被"飞读"的机会。
- 落地无惩罚——本城没有坠机概念，Touchdown 永远温柔，随时重新蓄力。

## 后果

- 玩家物理循环需要分态（Walk / Shuttle），碰撞代码复用但地面判定从"仅街道层"泛化为"任意 AABB 顶面"。
- 海拔 Rail、蓄力条为 DOM HUD 元素，textmode 管线不变。

## 修订 1 — 手感与按键（玩家反馈）

1. **按键重映射**：空格 = 步行蓄力弹射 / 空中沿视线推进；Shift = 步行跑步、穿梭机主动刹车（沿速度反方向 30m/s²，永不反向穿越零点）；E 退役。
2. **落地必定取消模式**：删除重落反弹——满蓄弹射的 ~23m/s 触地曾以 0.35 系数弹回 8m 并把玩家带离屋顶几十米（被感知为"传送到非房顶"）；现在重落只加大震屏（0.85）。
3. **侧向抓地**：速度分解为前向/侧向，侧向以 3.5/s 阻尼衰减——拐角时速度跟随视线，前向动量保留，笨重感消除。
4. **镜头侧倾 + 滞后**：穿梭机中 yaw 以 9/s 弹簧滞后跟随输入，转向时侧倾 ±7°（随 |pitch|→90° 渐隐），步行保持刚性镜头。
5. **俯仰自由**：穿梭机俯仰放宽到 ±90°（可直视天顶/脚下），步行维持 ±83°。

## 修订 2 — 零重力（玩家反馈）

1. **移除重力与速度升力**：穿梭机完全重量化，松开一切输入后仅由阻力（dragV 0.22/s）缓慢定住。走出屋顶边缘不再坠落而是悬停。
2. **弹射改为固定冲量**：v0 = 4 + 16×蓄力（m/s），上升距离 ≈ v0/0.22 ≈ 18-91m；蓄力条预览读数同步改为 v/dragV。
3. **落地语义不变**：接触任意固体表面即 Touchdown；急降（俯视 + 空格）可达重落震屏阈值。
4. **白天曝光回调**（同轮玩家反馈）：正午 sunI 1.75→1.1、amb 0.72→0.6、雾色加深（0xb8cfd8→0x9cbcd0）——此前漫反射把立面推过 1.0 全屏裁剪成"白蒙蒙"。
