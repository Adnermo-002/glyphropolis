# 0003 — 建筑混编：参考项目造型语言的重释

日期：2025（grill 会话定案）
状态：Accepted

## 背景

四个参考项目（asciicker / asciicity / ascii-city-walkable / ascii-city-osm）的考古报告给出了可移植的建筑表现技巧清单。决策：如何将它们融入本城。

## 决策

1. **灵感混编，不忠实复刻**：提取造型语言，用本城的真 3D→textmode 管线、昼夜与雨夜美学重新演绎。
2. **混入现有 district，不新增 district**：约 40% 的 lot 按区块权重替换为新原型；同一 Seed 生成结果保持确定。
3. **四种新原型**：
   - 矮排屋（residential）——walkable facadeChar 窗格语法：层线 `=`、亮窗 `8/O/*`、暗窗 `o/.` 的 UV→glyph 规则；
   - 腰线塔（midtown）——asciicity 的 1/3 高度 ledge；
   - 天线塔（downtown）——1/4 概率天线 + 屋顶 `*`；
   - 檐口地标大厦（取代现有地标造型，集大成）——asciicker 层差轮廓（glyph pass 用深度差画 `-_ ` 檐口线）+ 天线 + 腰线全叠。
4. **夜景活性**：窗光呼吸（sin × tick hash）叠进现有 hash 亮窗；阶梯雾（雾走 palette 阶梯不连续）保 ASCII 味。
5. **明确不搬**：软光栅器/DDA/2D 剪影墙/OSM 逐点光栅化（管线代差）；**OSM 真实城市导入器留给 v2**。

## 理由

- 40% 混编让"这栋楼不一样"的惊喜频率刚好，同时保住霓虹雨夜的整体感。
- 层差檐口线是 120-190m 地标在字符分辨率下的可读性关键（报告称最大杀器）。
- 全部技巧为小-中工作量且互相独立，适合一次表现力大版本。

## 后果

- 建筑着色器新增窗格语法分支与呼吸项；glyph pass 新增深度差檐口检测；citygen 的 lot 生成器按 district 选原型池。
- 新原型参数全部进 Seed 哈希，城市确定性与分享性不变。
